# GTNH seed map (RWG2)

An in-browser seed viewer for GT New Horizons 2.9, which uses Realistic World Gen 2 (2.0.6) with the default `RWG2_CONTINENTS` world type.

Enter a seed to see continents, oceans, islands, volcanoes, biomes, rivers and terrain height. The **Height** and **Relief** modes show ground level; hover or tap anywhere to read the Y level.

- Everything runs in your browser; there is no server.
- It is a port of the mod's world-generation code. Two independent transcriptions agree bit for bit; spot checks against a real game are welcome.
- Worlds switched to OpenSimplex noise with RWG's noise command, or using a custom `rwg2.cfg`, generate differently.

Open `index.html` locally or visit the GitHub Pages site.
