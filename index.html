      About this map

      A port of the overworld generator from Realistic World Gen 2 (version 2.0.6) as GT New Horizons 2.9.0 ships it: the default RWG2_CONTINENTS world type with RWG2's default settings, Biomes O' Plenty and Thaumcraft biomes. It covers continents, oceans, islands, volcanoes, climate zones, biome placement, rivers and terrain height.

      The code was ported from the mod's source by two separate transcriptions that agree bit for bit on biomes, rivers and heights, including volcanoes and coastlines. Neither has been compared with a running game yet.

      The map shows the biome RWG2 places at each point. The F3 screen can differ near biome edges, because the game picks each column's displayed biome from the blended neighbours and swaps in river biomes.

      Terrain heights are the top block of the ground before caves, lava caves, trees and other features. At 1 px = 4 blocks or closer they are exact; between 8 and 16 blocks per pixel the map uses a faster estimate that can be off near biome borders. Sea level is Y 62. Worlds switched to OpenSimplex noise with RWG's noise command generate differently.
